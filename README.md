## 🚀 How to Install & Use in WordPress

### Option 1: Direct Theme Upload
1. Download or locate `md-nutrition-theme.zip`.
2. Go to your **WordPress Admin Panel** (`yourdomain.com/wp-admin`).
3. Navigate to **Appearance > Themes > Add New > Upload Theme**.
4. Choose `md-nutrition-theme.zip` and click **Install Now**.
5. Click **Activate**.
6. Set Homepage: Go to **Settings > Reading**, select **A static page**, and choose your homepage.

### Option 2: Elementor Page Builder
If you are already running WordPress with **Elementor**, open [`WORDPRESS_BUILD_GUIDE.md`](./WORDPRESS_BUILD_GUIDE.md) for the exact container widths, padding, color hex codes, and widget settings.
